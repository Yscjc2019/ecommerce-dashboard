# 📊 电商全链路数据分析与 RFM 客户分层 BI 看板

基于 **Python + SQLite + Pandas + Streamlit + Plotly** 构建的轻量级商业智能（BI）交互式数据分析看板。项目覆盖从底层多表数据库仿真建模、销售与退款全链路监控，到基于 RFM 模型的客户价值分层及自动化云端部署的完整闭环。

🔗 **在线交互演示**：[点击访问 Streamlit Cloud 在线看板](https://streamlit.app)

---

## ✨ 核心功能模块

### 1. 📊 销售与退款全景总览
* **核心指标动态联动**：实时核算**总销售额、总订单数、平均客单价、总退款金额**及扣除退款水分后的**净销售额**。
* **多维度交叉下钻**：支持按“商品类别”与“城市”进行全局动态筛选（支持留空默认全量展示）。
* **趋势与归因可视化**：
  * **各品类销售额对比**：柱状图直观呈现各业务线营收贡献。
  * **周度销售额趋势**：将原始日度订单按周聚合，平滑短期波动噪音，精准捕捉销售波峰。
  * **退款原因归因分析**：通过 `LEFT JOIN` 关联退款表，以环形图定位“物流时效”等核心退货诱因。
* **订单明细与数据导出**：支持筛选后订单明细的格式化展示（自动隐藏空值异常、自适应列宽）及一键导出 CSV。

### 2. 💎 客户价值分层系统（RFM 模型）
* **自动化五分位数打分**：基于剔除退款后的用户**净消费总额（Monetary）**，结合**最近一次消费间隔（Recency）**与**消费频次（Frequency）**，动态计算每位用户的 RFM 得分。
* **八大运营人群划分**：自动化识别并划分出**重要价值客户（核心金主）、重要唤回客户（高消费流失预警）、重要深耕客户、潜力客户、新客户、流失客户**等 8 类精准人群。
* **跨端自适应可视化**：采用带动态留白、置顶水平色阶图例及高对比度配色的横向柱状图，确保桌面端与手机移动端均能完整展示所有分层数据标签。
* **精准运营名单导出**：支持运营人员按客户分层二次圈选目标人群，并一键导出营销触达名单（CSV）。

## 🛠️ 技术栈与项目结构

* **数据存储与查询**：SQLite3（`LEFT JOIN` 多表关联、`COALESCE` 空值处理、分组聚合）
* **数据处理与建模**：Python 3.11、Pandas、Faker
* **可视化与 Web 框架**：Streamlit、Plotly Express
* **工程部署**：GitHub + Streamlit Community Cloud（CI/CD 自动化发布）

```text
ecommerce-dashboard/
├── dashboard.py          # Streamlit 主应用程序（含数据加载、RFM 建模与双标签页可视化）
├── shop.db               # SQLite 仿真业务数据库（包含 users、orders、refunds 三张关联表）
├── requirements.txt      # 云端运行环境依赖清单
└── README.md             # 项目说明文档
```

## 🚀 本地运行指南

1. **克隆或下载本项目到本地**
   ```bash
   git clone https://github.com
   cd ecommerce-dashboard
   ```

2. **安装依赖库**
   ```bash
   pip install -r requirements.txt
   ```

3. **启动看板服务**
   ```bash
   streamlit run dashboard.py
   ```
   启动后浏览器将自动打开预览界面。
